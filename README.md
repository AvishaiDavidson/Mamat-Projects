## 🚀 Getting started

**1. Clone the repository**

```bash
git clone https://github.com/AvishaiDavidson/Mamat-Projects.git
cd Mamat-Projects
```

**2. Open an assignment directory** (once assignments are available)

```bash
cd HW1
ls -la
```

**3. Build and run**

Build commands depend on the language and structure of each assignment. Follow the instructions in the assignment's own `README.md` or build configuration. For example, **if** an assignment includes a `Makefile`:

```bash
make
```

> A `Makefile` and the `HW1` directory are examples only; they may not exist yet.
